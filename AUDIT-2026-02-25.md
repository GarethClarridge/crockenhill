## ✅ Completed

### Critical

- **N+1: Sermon meta/podcast accessors** — `getMetaDescriptionAttribute()` and `getPodcastSummaryAttribute()` in `Sermon.php` now use `$this->relationLoaded('preacherProfile')` guard, matching the pattern already used in `getPreacherUrlAttribute()`.

- **N+1: Meeting event attributes** — `getUpcomingEventsAttribute()` and `getPastEventsAttribute()` in `Meeting.php` now use `$this->calendarEvents()->...` instead of a raw `CalendarEvent::where(...)` query.

### High

- **XSS: JSON-LD output** — Added `JSON_HEX_TAG | JSON_HEX_AMP` to all three `{!! json_encode(...) !!}` blocks: `sermon.blade.php` (×2) and `components/breadcrumbs.blade.php`. Prevents `</script>` injection via sermon titles.

- **Nav cache invalidation** — Investigated; already correctly handled. `SitemapCacheObserver` calls `Cache::forget('nav_pages')` on every Page created/updated/deleted. No change needed.

- **Page image URL duplication** — Four near-identical accessor methods (`heading_image_url`, `heading_image_tablet_url`, `heading_image_mobile_url`, `heading_image_small_url`) in `Page.php` consolidated into a single `private resolveHeadingImageUrl(array $conversions, string $size): ?string` helper. Removed ~80 lines of duplication.

### Medium

- **PageController `firstOrFail()`** — Replaced manual `first()` + `if (!$page) abort(404)` with `firstOrFail()`.

- **View composer scoping** — `View::composer('*', ...)` for `$user` narrowed to `'components.layout.header'` only. The admin user views were confirmed to use `$user` only as a loop variable (unrelated to the composer).

- **EditSermon preacher query** — `Preacher::active()->orderBy('name')->pluck(...)` moved from `render()` to `mount()`, stored in a `$preacherOptions` public property. No longer runs on every Livewire re-render.

- **AppServiceProvider cleanup** — Added `: void` return types to `boot()` and `register()`. Replaced `switch/case` with `match` for transcription service binding.

- **Dead code removed** — Commented-out `getPointsAttribute` / `setPointsAttribute` accessors from `Sermon.php`; commented-out Dusk provider from `AppServiceProvider.php`.

- **Markdown rendering** — Changed `'html_input' => 'strip'` to `'html_input' => 'escape'` in the transcript block in `sermon.blade.php`.

- **Stack traces in failure emails** — `LivestreamProcessingFailed::sanitiseStackTrace()` now: strips server base paths (`base_path()`), redacts credential-like patterns (`password=`, `secret=`, `token=`, `api_key=`, `auth=`), and truncates to 3000 chars. File path also stripped of base path.

## ⬜ Remaining

### Test Coverage Gaps (Medium effort)

The following areas have little or no test coverage:

- **API upload endpoints** — no feature tests for `POST /api/media/{type}` (audio, video, livestream)
- **Middleware** — no tests for `EnsureUserIsAdmin` or `EnsureMediaProcessingAccess`
- **Rate limiting** — no tests verifying `media-upload` rate limiter enforces limits
- **Admin Livewire CRUD** — limited tests for `ListSermons`, `ListMeetings`, `ListPages`, `EditSermon`
- **Livewire components** — `ProcessingLogsViewer`, `MediaUpload` subcomponents (Status, Progress) untested
- **Livewire events** — no tests for event listener/dispatch flows
- **Edge cases** — duplicate sermon slugs, XSS in sermon fields, file cleanup on failed uploads

### Factory Improvements (Medium effort)

- `SermonFactory` — doesn't set `preacher_id` or realistic file paths; no states for `withTranscript()`, `withVideo()`, `withPreacher()`
- `MediaProcessingLogFactory` — always has `sermon_id: null`; needs `withSermon()` state and `withOwner()` state
- No `CalendarEventFactory` exists at all

### Low Priority (Deferred)

- **Route redirect consolidation** — ~40 individual redirect definitions in `web.php`; could be driven from a config array
- **Duplicate middleware chains in `api.php`** — repeated middleware stacks could use a shared route group
