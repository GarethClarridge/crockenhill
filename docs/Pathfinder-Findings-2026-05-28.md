# 🔗 Pathfinder: Broken links and missing assets on Meetings and Redirects

**Summary:** Multiple broken internal links and stale redirects discovered during a diagnostic crawl. Hardcoded routes in Blade templates point to a deprecated prefix, and a permanent redirect points to a non-existent page slug.

## 1. Broken Internal Links (Meetings)
**Surface:** `/meetings` (Admin/Seeded List)
**Reference:** `resources/views/meetings/index.blade.php` line 31.
**Issue:** Hardcoded `<a href="/meetings/{{ $meeting->slug }}">` returns 404.
**Verification:**
- `GET /meetings/1150` -> 404
- `route('meetings.show', ['meeting' => '1150'])` -> `http://localhost/community/1150` (returns 200)
**Affected items:** 13 seeded meetings.
**Suggested action:** Update the Blade template to use `route('meetings.show', $meeting)` instead of a hardcoded path.

## 2. Stale Permanent Redirect
**Surface:** `config/redirects.php`
**Issue:** `'about-us/privacy-policy' => '/church/privacy-policy'` points to a 404.
**Verification:**
- The `pages` table contains a record with slug `privacy-notice` in the `church` area, but no `privacy-policy`.
- `GET /church/privacy-policy` -> 404
- `GET /church/privacy-notice` -> 200
**Suggested action:** Update the redirect target to `/church/privacy-notice`.

## 3. Missing Sermon Assets
**Surface:** `/christ/sermons`
**Issue:** `Sermon::audio_file_path` entries point to files missing from the default storage disk.
**Verification:**
- `Storage::disk('default')->exists('christmas-2024-morning.mp3')` -> false
- Total missing audio assets: 32 (all seeded sermons).
**Likely cause:** Seeded data references mock filenames that do not exist in the environment's `storage/app/public/sermons` directory.
**Suggested action:** Verify if these assets should be generated by a seeder or if they represent a regression in the dev environment setup.
