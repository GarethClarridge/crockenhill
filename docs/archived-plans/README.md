# Archived plans and historical reports

Completed or superseded plans, specs, backlogs, and audits. Kept because they explain *why*
things are the way they are; **nothing in here describes the current state of the codebase.**

Rules for agents:

- **Never work from a file in this folder.** Active work lives in
  [`../plans/README.md`](../plans/README.md) and [`../issues/README.md`](../issues/README.md).
- Files arrive here with a dated archival header at the top saying what superseded them and
  what (if anything) is still worth trusting. If you consult one, read that header first.
- Beyond adding an archival header when a file is moved in, don't edit these files — they are
  snapshots.
- There is no index of this folder; filenames and headers are the index. Deleted (rather than
  archived) documents live in git history.
