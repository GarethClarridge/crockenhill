# Product Overview

## Crockenhill Baptist Church Website

This is a Laravel-based church management system for Crockenhill Baptist Church (crockenhill.org). The application manages church content including sermons, meetings, pages, and calendar events.

## Core Features

- **Sermon Management**: Upload, organize, and display sermon recordings with metadata (preacher, series, Bible references, transcripts)
- **Meeting Management**: Schedule and display church meetings with recurring event support
- **Page Management**: Content management system for church pages and announcements
- **Calendar Integration**: Google Calendar synchronization for church events
- **Member Areas**: Authentication and member-specific content

## Current Focus

The system is actively being enhanced with automated sermon processing capabilities that use AI to:
- Transcribe sermon audio files automatically
- Extract metadata from filenames and audio properties
- Generate sermon titles and identify series information
- Extract Bible passage references and sermon points
- Create structured transcripts with headings

## Target Users

- Church administrators managing content
- Members accessing sermons and church information
- Visitors browsing church information and resources
